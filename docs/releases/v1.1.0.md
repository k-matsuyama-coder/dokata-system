# v1.1.0 日付メモ機能アップデート

リリース日: 2026-07-26

## 新機能

月間工程表と2ヶ月工程表の日付ヘッダーに、日付単位のメモを登録できるようになりました。

## 操作方法

1. メモがない日付へマウスを合わせます。
2. 日付横の吹き出しアイコンを押します。
3. メモを入力します。
4. 保存ボタンを押します。
5. メモが登録された日付には青丸が表示されます。
6. 日付へマウスを合わせるとメモ内容を確認できます。

## データベース変更

`assignment_date_memos` テーブルを追加しました。

一意条件:

- organization_id
- work_date

## 対象画面

- 月間工程表
- 2ヶ月工程表

## 注意事項

データベースマイグレーション適用後に、アプリケーションをデプロイしてください。
